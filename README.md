# Kamu Pusulası veri akışı

Bu dal, `.github/workflows/feed.yml` tarafından otomatik üretilir; elle düzenlemeyin.

- `ilanlar.json` — Kariyer Kapısı (T.C. Cumhurbaşkanlığı) kamu işe alım ilanları. Kaynak: https://kariyerkapisi.gov.tr
- `haberler.json` — Resmî Gazete günlük fihristi ve kamu personelini ilgilendiren maddeler. Kaynak: https://www.resmigazete.gov.tr

Haber ajanslarının içerikleri kullanım koşulları nedeniyle bilinçli olarak dahil edilmemiştir.
